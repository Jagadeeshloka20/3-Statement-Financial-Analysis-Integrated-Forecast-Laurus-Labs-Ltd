## Real business problem
Laurus Labs is growing CDMO and Affordable Medicines while investing heavily in capacity, advanced manufacturing and R&D. The finance question is whether growth and operating leverage can translate into sustainable cash generation while working capital, CapEx and debt remain controlled.

## Model
Historical Income Statement + Balance Sheet + Cash Flow → driver analysis → five-year integrated forecast → working capital → PP&E/D&A → debt/interest → retained earnings → cash → balance-sheet check → scenarios → KPI dashboard.

## Verification standard
- Historical FY2024–FY2026 core figures are sourced from official Laurus Labs reports/results.
- FY2026 audited consolidated results and cash-flow statement were checked line-by-line for the core model inputs.
- FY2025/FY2024 consolidated balance-sheet data were checked against the FY2024-25 annual report.
- Every forecast input is labeled as an analyst assumption.
- The workbook contains a model-integrity check; historical balance sheets reconcile to total assets = equity + liabilities.

# Power BI — Laurus Labs 3-Statement Dashboard
1. Executive Financial Health — Revenue, EBITDA, PAT, CFO, FCF, Debt, Cash.
2. Income Statement — Growth, EBITDA margin, PAT margin, segment mix.
3. Balance Sheet — Inventory, receivables, payables, NWC, debt.
4. Cash Flow — CFO, CapEx, FCF, dividends.
5. Forecast & Scenarios — Base/Bull/Bear growth, margin, CapEx, working capital.
6. Model Integrity — source status, assumptions, missing values, balance check.
